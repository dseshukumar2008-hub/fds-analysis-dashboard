# Game Sales Analytics Dashboard

## Files

- `app.py` — Streamlit dashboard
- `vgsales.csv` — add the Kaggle Video Game Sales dataset to the repository root
- `requirements.txt` — required Python packages

## GitHub structure

```text
fds-analysis-dashboard/

```

## Streamlit configuration

Repository: your GitHub repository  
Branch: `main`  
Main file path: `app.py`

The dashboard does not use the old Platform/Genre/Release-Year filter panel.

It includes:
- Project Overview
- Global Sales Distribution
- Publisher Analysis
- Release-Year Trend
- Advanced Platform Radial View
- Genre Sales Composition
- Platform × Genre Heatmap
- Machine Learning Summary
- Research Question Findings
- Key Insights & Recommendations
